exchange服务器安装

环境：windows server 2016 、exchange server 2016 cu12

搭建流程：

1）配置windows server 2016 网络、计算机名，加入域

2）域管账户登录域机器，运行exchange的setup.exe

3）不使用推荐设置、不检查更新、禁用恶意软件扫描

4）根据报错和所给链接安装相应的前提条件

5）前提条件安装后，还要注意将所有域控打开，否则第一步会因为无法复制相应信息报错

6）IE打开链接：http://localhost/ecp，用域管账户登录管理中心

  1. 管理员添加邮件用户,从域中选择域用户添加（注意：创建和删除用户，都会同步到域中）

8）登录域用户邮箱的exchange管理中心 ：https://exchange.com/ecp

9）登录exchange客户端：https://exchange.com
